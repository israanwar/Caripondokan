# Caripondokan

Public portfolio reconstruction for a long-term boarding-house discovery experience.

## Direction

Caripondokan helps a prospective resident prepare for a room survey. It presents room examples as comparison material for light, facilities, study readiness, and questions to bring before visiting.

## Run locally

```bash
npm install
npm run dev
```

## Build checks

```bash
npm run build
npm run test:sites
```

All room imagery and examples are created for this portfolio reconstruction. This project does not contain live inventory, availability, pricing, property reviews, booking, or address data.
